01 · Production app · the flagship

BeforeYouGo

Open BeforeYouGo ↗

A system that makes Israeli bureaucratic processes accessible to residents who are not citizens. It reads the user's real documents and shows what's in order, what's missing and what to handle first, starting with the driving licence.

The real process is mapped end to end, down to the source clause behind every requirement. The rules engine makes every decision. The LLM reads documents and phrases the answer inside those rules.

  • Serverless on AWS, infrastructure cost cut by more than 97%
  • 611 automated tests on every change, then it deploys on its own
  • Every model answer is checked on the server and guarded against prompt injection
  • Full Hebrew and English

How it fits together

The agent system

Runs daily

The skills, agents and automations in the index form one system that runs my working day. Briefings, posts and weekly reviews run on a schedule, all reading from one shared memory: a knowledge base of every project, decision and lesson, connected.

It learns from mistakes. When something breaks, the cause and the fix are logged so it never retries a known wrong approach. It's plain files on purpose, so it can move to any agent tool.

  • 7 scheduled automations, 15 skills, 3 agents, 2 hooks
  • 402 connected pages of memory, loaded before every session
  • A hook stops any message holding a key or token before it's sent
Agent pair

Upgrade agents

A scout reads what changed in the field and proposes upgrades twice a week. Nothing gets built until I approve. Then a builder makes the change, tests it, and ships it, with a note on how to use it and how to undo it.

The process · Every build

Plan, build, review, ship.

01

Plan

The problem, the costly mistake, and a definition of done that can be proven. Nothing starts without it.

02

Build

Run, test, fix, in a loop until the definition of done is met with real evidence. It stops after six failed tries.

03

Review

A separate checker agent, never the one that built it, proves every item and runs quality and security checks.

04

Ship

It runs once for real where it lives. Then a secret check, a commit, and the decisions and lessons are saved.

Principles

How I work.

Rules decide. The model phrases.

Where a wrong answer costs someone, a deterministic engine makes the call and the LLM works inside it.

Every decision is written down with its reason.

232 numbered decisions on BeforeYouGo alone. Nothing gets argued twice.

It gets better because I train it.

Every correction becomes a standing rule. Every failure goes to an error log with its fix.

No lock-in.
